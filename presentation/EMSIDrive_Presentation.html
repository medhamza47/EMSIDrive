Architecture & Technologies

Application Mobile — Flutter (Dart)

• Application Android fluide
• Mode clair et mode sombre
• Carte interactive de Marrakech

Serveur Backend — Spring Boot (Java 21)

• API REST sécurisée par JWT
• Gestion des trajets et réservations
• Notifications push avec Firebase

Base de Données — PostgreSQL (Docker)

• Stockage des comptes et trajets
• Historique des messages et avis

IA & Administration — PaddleOCR, OpenRouter & Angular

• Site Web Admin en Angular 21
